Curriculum-Based Measurement for Written Expression (CBM-W):

The "How to" Guide

This module provides a practical guide to Curriculum-Based Measurement for Written Expression (CBM-W) and how it is used within a problem-solving approach for data-based instructional decision making.

  1. You will learn how to select prompts, administer CBM-W, and score probes.
  2. You will learn how to use CBM-W in a practical setting, including:
    1. Administer, score, and graph data from CBM-W
    2. Discuss appropriate uses of CBM-W for data-based instructional decision making.
