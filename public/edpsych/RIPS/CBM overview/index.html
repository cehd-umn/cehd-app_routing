Curriculum-Based Measurement (CBM) Overview

This module provides an overview of Curriculum-Based Measurement and how it is used within a problem-solving approach for data-based instructional decision making.

  1. You will learn about the purpose of CBM within a problem-solving framework.
  2. We will talk about how the CBM can be used to:
    1. Identify and define problems
    2. Explore, apply and look at the effects of solutions.
