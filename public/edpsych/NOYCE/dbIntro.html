Literature Database

Introduction

Presently, this online database contains 717 articles, from 1961 to present, categorized according to topic to support searching.  This database was last updated December 2009.

This database is aimed to be used by both researchers and practitioners, is inclusive of articles from a variety of perspectives, and can be searched using a range of selection criteria.

The extensive review of existing literature concentrates on the nexus between published work on recruitment and retention both in general and in STEM programs, and includes alternative certification.  

How to perform a search in the database

Please select one of the following search methods:

Structured Search

  • Retrieves resources as categorized in the database. This query allows you to use database categories to frame your search.

Retrieve All

  • Retrieves all resources in the database.
