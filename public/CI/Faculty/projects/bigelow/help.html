Play video / read script
links don't work 		This site utilizes JavaScript to make videos and scripts open in a new window that floats above the referring page. If JavaScript is not enabled by your browser the links will not work. You can enable the use of JavaScript by setting the browser's "preferences" in Netscape or set "internet options" if you are an Internet Explorer user. Please consult the help section of your browser for further instruction on enabling JavaScript. 
Video won't play You need QuickTime 3.0 or higher to view the video clips on this site. If you do not have QuickTime you can download it for free at http://www.apple.com/quicktime/ for either Macintosh or Windows compatible computers. Please note: you will see an option to purchase a "Pro" version of QuickTime, this is not necessary. The free version of QuickTime will play the videos on this Web site. 
Get this Web site on a CD This site was designed for use with a high speed connection. If you lack a fast enough internet connection to view the video on this Web site you can request a copy of the Web site on a CD. You can then view the Web site from the CD drive on either your Macintosh or Windows compatible computer. Please contact Martha Bigelow at mbigelow@umn.edu or 612-624-7087 to request a copy.
