XML and You!

XML has one job, move data. It is the real star behind all the feeds we consume from the news blog, people tool, events calendar, program tool, and even the Google search results. All of those tools and sites send use XML to consume.

XSLT is a type of style sheet that sorts XML and adds HTML so the data can transform into content. The T stands for transform. Together the XML and XSLT keep our pages up to date.

Using a people feed here are two methods for grouping by letter
