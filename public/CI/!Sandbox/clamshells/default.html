Adding a Clamshell Menu

Firelfy comes equipped with a clamshell menus built in and ready to go. If you want to see them in action, try the "layouts" section on the navigation

How do they work?

Just go into the navigation incldue file, found in

  • attributes>includes>nav.asp

Open that up, and away you go. Everything is in unordered lists. Just edit it right in the design view. If you want a subsection, just hit the indent button, or hit the tab key, and you'll go in a level.

Keys to Success

Keep the ul structure of the navigation clean, the parent ul: <ul id="navblock">
Nested ul's are: <ul class="submenu">

When adding more pages to the clamshell navigation keep in mind it will behave erratically if:

  • List items are not linked to pages
  • Identical links appear in more than one place
  • The default page in a directory is not linked in the navigation

What if you want to take them out?

Easy enough... 2 steps.

  1. Remove the java script file from the document header (it's where you find all the CSS files and stuff). It actually has a comment telling you which file to delete.
  2. Remove the java code from the navigation include (it lives at... attributes>includes>nav.asp), the code looks like...
    • <script type="text/javascript"> ddtreemenu.createTree("navblock") </script>
