Adding feaures to the side of your page.

How to add features:

You have a couple of options...

  • Option 1: Copy this page.
  • Option 2: Make a new page
    • File>New>(it asks if you want to do it from a template)>choose the "Features" template
  • Option 3: Convert an existing page
    • Modify>Templates>Apply Template to page...>(it will ask which template, so just choose "Features")

Working wtih features:

Ok, now you've got features boxes, yeah! Now what?

Different boxes

These boxes are all the same, the just have a class that changes the color, nothing too fancy. We picked 3 colors that goe with the theme on this page.

Changing colors

The colors all come from the stylesheet "firefly-features.css". Actually, evernthing that's different about this page, from a full width page, comes from this style sheet.

Go in there, and look for the end of the section on Features Boxes, you'll see the colors. Each box color thas two entries for the color, one for the Heading of the box, another for the border around it, just change those colors, and you're set!
