Google Search Tabs

Yes! You too can have custom search results! The Firefly set comes complete with tabbed search results, turn them on now for exciting fun!

Point the Search Box

The search box up in the U header needs to know to point to your form.

Open the file attributes/includes/UofM-header.html and replace the form action.

If it is still pointing to the Firefly template it will look like this:

<form action="/DWT/!Firefly/Search/default.html"

If someone set the templates up for you, the form might be pointing to the college search page:

<form action="/Search/default.html"

If you are using this template to update an existing site, the search box might be pointing to the very old search results page and it will look like this:

<form action="http://google.umn.edu/search"

If this is the case, replace the old UofM-header.html file with the one from the Firefly set or replace all of the <form> code in the old header with the new form code.

Anatomy of the Search Results Page

The search results page has its own DWT because it needs more support files than the rest of the site.

The <head>

It requires these CSS files which are contained in the Firefly set:

<link href="../CSS/tabbed-search.css" rel="stylesheet" type="text/css" />
<link href="../CSS/ui-tabs/jquery-ui-1.7.2.custom.css" rel="stylesheet" type="text/css" />

And the JavaScript files, which are called off the root:

<script src="/attributes/js/jquery-1.3.2.min.js" type="text/javascript" language="javascript"></script>
<script src="/attributes/js/jquery-ui-1.7.2.custom.min.js" type="text/javascript"></script>
<script src="/attributes/js/jquery.url.min.js" type="text/javascript" language="javascript"></script>
<script src="/attributes/js/search.js" type="text/javascript" language="javascript"></script>

// Edit tabs here

This section looks daunting, but it is easy! Don't want a tab? Delete the line. Adding a tab, copy a line. Just watch the pattern and keep the numbers in the [] straight, they start with 0.

The trickiest part is to have the search occur within a section of the college, like adding and academic unit. Let's use Kinesiology for example. If I added a KIN tab, by copying the CEHD tab... setting KIN to position [0], CEHD to [1]... I would just want Kinesiology results so I would look for:

http://google.umn.edu/search?&q="+query+"&site=tc_education

Watch closely, right after query+" add this line:

+inurl:cehd.umn.edu/Kin/

So you will end up with:

http://google.umn.edu/search?&q="+query+"+inurl:cehd.umn.edu/Kin/&site=tc_education

Easy right? If you wanted to search in CAREI, just replace Kin with CAREI

Body of the Page

The body of the page simply contains a call to the JavaScript

<script type="text/javascript">
showResults()
</script>

Style the Look

How your tabs look is all now controlled with CSS and XSLT, let your imagination run free!
