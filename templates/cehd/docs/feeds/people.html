Request parameters

Request parameters match parameters from the People Tool LinkPro. It's best to use that that to find the combination of events you want and then pass the matching parameters to http://www.cehd.umn.edu/services/people-tool/.

For example, if I check Research - Research topic tags > Access to Education in LinkPro and click the "generate xml link" button, I get http://apps.cehd.umn.edu/people/admin/XmlFeed.aspx?tg=349.

We just need the "en", "nm" or "tg" parameters from that link and send a GET request to http://www.cehd.umn.edu/services/people-tool/?tg=349 to return the same data in JSON format.
