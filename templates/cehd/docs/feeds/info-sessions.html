Request parameters

Request parameters match parameters from the Info Session LinkPro. It's best to use that that to find the combination of events you want and then pass the matching parameters to http://www.cehd.umn.edu/services/info-sessions/.

For example, if I want a feed that matches the data in the "TA-NonEd" RSS feed in the page linked above, all I need is the value for the "code" query parameter. So RSSFeed.aspx?code=TA-NonEd translates to http://www.cehd.umn.edu/services/info-sessions/?code=TA-NonEd.
