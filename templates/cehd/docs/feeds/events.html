Request parameters

Request parameters match parameters from the Events Calendar Tool LinkPro. It's best to use that that to find the combination of events you want and then pass the matching parameters to http://www.cehd.umn.edu/services/events/feed/.

For example, if I check Start > Today and then check "Public Calendar" under "Collegewide Calendar" in LinkPro and click the "generate xml link" button, I get http://apps.cehd.umn.edu/events/Admin/XMLFeed.aspx?&q=6&r=3&t=170.

We just need the "r", "q" and "tg" parameters from that link and send a GET request to http://www.cehd.umn.edu/services/events/feed/?q=6&r=3&t=170 to return the same data in JSON format.
