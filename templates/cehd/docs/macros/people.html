The code explained

See the page for the CSS loader for specific information about setting that up.

As always, remember to import the macro at the top of the page:

{% verbatim %}
    {% import "macros/people/people.html" as peoplefeed %}
            {% endverbatim %}

The first thing you'll need to know is the ID of the tag from the people tool. This feed:

https://apps.cehd.umn.edu/people/admin/XmlFeed.aspx?tg=466

has a tag ID of "466" (tg=466). That's the first thing you need to pass into the macro (see above).

Next, pass in a selector for the element that the macro will use to render the results. In this example, it's the ID #people-container.

Next is the name of the template you wish to use to render the results from the people tool. These templates use Nunjucks. Nunjucks is a JavaScript templating engine that has syntax almost identical to Twig, so it should look familiar. In this example the name of the template is list.html.

But where is that template? That's the next thing you pass into the macro. In this example it's in:

"/assets/dist/views/cehd/people/"

Since Nunjucks templates are handled by the browser, the templates have to be somewhere publicly accessible. Thus our templates are in /public/assets/dist/views/cehd/people/ for this example.

Put that all together and you can find the template at /public/assets/dist/views/cehd/people/list.html and it looks like this:.

{% verbatim %}
    <ul class="no-bullet">
    {% for person in data.people %}
        <li>
            {% if person.internetId|is_string %}
                <a href="{{ data.config.base_url }}/people/{{ person.internetId }}/">{{ person.lastName }}, {{ person.firstName }}</a>
            {% else %}
                {{ person.lastName }}, {{ person.firstName }}
            {% endif %}
        </li>
    {% endfor %}
    </ul>
            {% endverbatim %}
