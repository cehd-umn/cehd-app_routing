The code explained

See the page for the CSS loader for specific information about setting that up.

As always, remember to import the macro at the top of the page:

{% verbatim %}
    {% import "macros/people/people.html" as peoplefeed %}
            {% endverbatim %}

The first thing you'll need to know is the internet ID of the person you want to pull in.

Next, pass in a selector for the element that the macro will use to render the results. In this example, it's the ID #person-container.

Next is the name of the template you wish to use to render the results from the people tool. These templates use Nunjucks. Nunjucks is a JavaScript templating engine that has syntax almost identical to Twig, so it should look familiar. In this example the name of the template is example.html.

But where is that template? That's the next thing you pass into the macro. In this example it's in:

"/assets/dist/views/cehd/people/"

Since Nunjucks templates are handled by the browser, the templates have to be somewhere publicly accessible. Thus our templates are in /public/assets/dist/views/cehd/people/ for this example.

Put that all together and you can find the template at /public/assets/dist/views/cehd/people/example.html and it looks like this:.

{% verbatim %}
    <dl>
        <dt>First and last name</dt>
        <dd>{{ data.person.nameFirstLast }}</dd>
        <dt>Brief bio</dt>
        <dd>{{ data.person.briefBio|safe }}</dd>
    </dl>
            {% endverbatim %}
