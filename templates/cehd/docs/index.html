The CEHD site has several custom CSS classes to make it easy to generate pages that match their designs. Most of the time you should be able to use a combination and HTML elements and CSS classes to make a page look the way it should.

Page Title Block

The Twig template engine is configured to build off of a "base" template that includes a lot of code that you shouldn't have to worry about.

Blocks start with {% verbatim %}{%{% endverbatim %}, the word block, and the block name and {% verbatim %}%}{% endverbatim %}.

For example, the "title" block looks like this: {% verbatim %}{% block title %}{% endverbatim %}.

Blocks must be closed with {% verbatim %}{% endblock %}{% endverbatim %}.

All together now, the title block looks like this:

{%- verbatim -%}
{# Set the title #}
{% block title %}
    My Page Title
{% endblock %}
{%- endverbatim -%}

The code above will generate this html on the page:

<title>My Page Title</title>

Other Blocks

main_content

Use the main_content block for the content of the page.

Every template already has this block set up.

{% verbatim %}
{% block main_content %}
    Your html content goes here.
{% endblock %}
    {% endverbatim %}

title_prepend and title_append

title_prepend allows us to prepend the same thing to multiple page titles. E.g., every page title can be prepended with "Department of Educational Psychology".

title_append is the same as title_prepend, but for appending, obviously.

meta_content

Much like the title and heading_1 blocks, you can insert a meta_content block on a template to populate a <meta name="description"> tag. 

{% verbatim %}
{% meta_content %}This is my page description for search engines to read{% endblock %}{% endverbatim %}
            

<meta name="description" content="This is my page description for search engines to read">

extra_css

If you need to create a brand new style that you can't find here, there's a Twig template block for that.


{% verbatim %}{% block extra_css %}
<style>
    .special-snowflake {
        color: white;
    }
</style>
{% endblock %}{% endverbatim %}

Template Variables

There are a handful of variables set up for use in all templates. You can insert variables anywhere using double curly braces: {% verbatim %}{{ }}{% endverbatim %}.

The department name is probably the one that is most useful. You can insert that anywhere by doing this:

{% verbatim %}{{ config.dept_name }}{% endverbatim %}

Inserting that code will output "{{ config.dept_name }}".

Hopefully that will help with using the department name in a consistent way.

Setting Your Own Variables

If you find that you're repeating yourself, you can define a variable using set, and insert it anywhere in the template. 

{%- verbatim -%}
{% set page_title = "Alumni" %}{# set the variable #}
{% block title %}
    {{ page_title }}{# use the page title variable for both the title and h1 #}
{% endblock %}
{% block heading_1 %}
    {{ page_title }}
{% endblock %}
{%- endverbatim -%}

Put all together a beginning template will look something like this:

{% verbatim %}{# this is important, don't delete it #}
{% extends "edpsych/layout/section.html" %}

{# Set a variable so we can use the same text for the title element and the h1 element #}
{% set page_title = "Current" %}

{# Use the variable for the page title #}
{% block title %}{{ page_title }}{% endblock %}

{# Use the same variable for the h1 #}
{% block heading_1 %}{{ page_title }}{% endblock %}

{# Insert custom CSS #}
{% block extra_css %}
    <style>
        .special-snowflake {
            color: white;
        }
    </style>
{% endblock %}

{# Put all the content in the main_content block #}
{% block main_content %}
    <h2>Heading 2</h2>

    <p>This is where my content goes.</p>
{% endblock %}{% endverbatim %}

Layout and Grid

All columns must be contained in two divs with .row and .container classes respectively.

Rows will create an element that always extends to 100% of the browser window. That can be handy as demonstrated below.

The container element will limit width to a maximum width of 1400px and center the layout on the page.


<div class="row">
    <div class="container">
        <p>All columns must be contained in a <samp>.row</samp>.</p>
    </div>
</div>

Important information about columns

Columns will not display correctly unless the last column is the last child element.

Works

    <div class="half">child</div>
    <div class="half">child</div><!-- last child -->

    <div class="half">child</div>
    <div class="half">child</div><!-- last child -->
</div>

<div class="parent">
    <div class="half">child</div>
    <div class="half">child (this element will have an extra right margin so it wraps)</div>
