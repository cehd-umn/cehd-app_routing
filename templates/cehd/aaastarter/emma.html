Emma's page

I will be trying my hardest to get this to look somewhat similar to the example layout. If it doesn't look right...it was meant to look like that:)

Your challenge is to replicate this layout using a blank template and the pattern library. If you get stuck try using the inspect feature in a browser rather than opening this page and looking at the source code directly.

Some of the elements on this page are using more than one class. The div wrapping this text for example is using span-10 push-2. In reference to the 12 grid system, this means it covers 8 columns and is pushed over 2 columns.

But that only adds up to 10! Yes, the last two columns are unused and the row ends so nothing floats up into the empty space on the right.
