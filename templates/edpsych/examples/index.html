The Ed Psych site has several custom CSS classes to make it easy to generate pages that match their designs. Most of the time you should be able to use a combination and HTML elements and CSS classes to make a page look the way it should.

Page Title and H1 Blocks

The Twig template engine is configured to build off of a "base" template that includes a lot of code that you shouldn't have to worry about. Included in that base template are the title and h1 tag.

You shouldn't include an h1 in your templates. To control what appears in those tags, use the title and heading_1 blocks.

Blocks start with {% raw %}{%{% endraw %}, the word block, and the block name and {% raw %}%}{% endraw %}.

For example, the "title" block looks like this: {% raw %}{% block title %}{% endraw %}.

Blocks must be closed with {% raw %}{% endblock %}{% endraw %}.

All together now, the title and heading_1 blocks look like this:

{%- raw -%}
{# Set the title #}
{% block title %}
    My Page Title
{% endblock %}

{# Set the h1 #}
{% block heading_1 %}
    My H1 Text
{% endblock %}
{%- endraw -%}

The code above will generate this html on the page:


<title>My Page Title</title>

<h1>My H1 Text</h1>

Other Blocks

main_content

Use the main_content block for the content of the page.

Every template already has this block set up.

{% raw %}
{% block main_content %}
    Your html content goes here.
{% endblock %}
    {% endraw %}

title_prepend and title_append

title_prepend allows us to prepend the same thing to multiple page titles. E.g., every page title can be prepended with "Department of Educational Psychology".

title_append is the same as title_prepend, but for appending, obviously.

meta_content

Much like the title and heading_1 blocks, you can insert a meta_content block on a template to populate a <meta name="description"> tag. 

{% raw %}
{% meta_content %}This is my page description for search engines to read{% endblock %}{% endraw %}
    

<meta name="description" content="This is my page description for search engines to read">

extra_css

If you need to create a brand new style that you can't find here, there's a Twig template block for that.


{% raw %}{% block extra_css %}
<style>
    .special-snowflake {
        color: white;
    }
</style>
{% endblock %}{% endraw %}

Template Variables

There are a handful of variables set up for use in all templates. You can insert variables any where using double curly braces: {% raw %}{{ }}{% endraw %}.

The department name is probably the one that is most useful. You can insert that anywhere by doing this:

{% raw %}{{ config.dept_name }}{% endraw %}

Inserting that code will output "{{ config.dept_name }}".

Hopefully that will help with using the department name in a consistent way.

Setting Your Own Variables

If you find that you're repeating yourself, you can define a variable using set, and insert it anywhere in the template. 

{%- raw -%}
{% set page_title = "Alumni" %}{# set the variable #}
{% block title %}
    {{ page_title }}{# use the page title variable for both the title and h1 #}
{% endblock %}
{% block heading_1 %}
    {{ page_title }}
{% endblock %}
{%- endraw -%}

Put all together a beginning template will look something like this:

{% raw %}{# this is important, don't delete it #}
{% extends "edpsych/layout/section.html" %}

{# Set a variable so we can use the same text for the title element and the h1 element #}
{% set page_title = "Current" %}

{# Use the variable for the page title #}
{% block title %}{{ page_title }}{% endblock %}

{# Use the same variable for the h1 #}
{% block heading_1 %}{{ page_title }}{% endblock %}

{# Insert custom CSS #}
{% block extra_css %}
    <style>
        .special-snowflake {
            color: white;
        }
    </style>
{% endblock %}

{# Put all the content in the main_content block #}
{% block main_content %}
    <h2>Heading 2</h2>

    <p>This is where my content goes.</p>
{% endblock %}{% endraw %}

Heading Tags

To maintain a consistent document structure, it's a good idea to try to only have one <h1> tag on the page. Since the <h1> tag is already used, start your content with an <h2> instead. Remember, headings are for structure, not presentation.

Heading Classes

In order to maintain a visual hierarchy, headings have matching CSS classes to control their sizes. For example:


<h1>This is what an h1 would look like</h1>
<h2>This is what an h2 would look like</h2>
<h2 class="h1">This is an h2 with the .h1 class</h2>

To make a half-width or two-thirds width column that is centered, use the .feature class.


<div class="half feature">
    <p>Half-width column that is centered</p>
</div>

    <p>Two thirds-width column that is centered</p>

To add a background with the correct shade of yellow and bigger margins to one of these, add the .emphasis class.


<div class="half feature emphasis">
    <p>A half-width column with yellow background</p>
</div>

Building on this further, you can use the .pull-quote class to bump up the font size for things like, well, pull quotes.

</div>
